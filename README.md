## À propos de ce dépôt

Les zips publiés ici alimentent le **système de mise à jour en un clic** du plugin :
WordPress vérifie ce canal et propose la nouvelle version directement dans l'admin.

- `latest/` — dernière version stable (zip + manifeste)
- `community-blacklist.json` — liste de blocage communautaire (numéros/aliases frauduleux COD)
